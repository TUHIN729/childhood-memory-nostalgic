A single-sentence childhood memory for the make.fun bounty
[Make the AI Judge Feel Nostalgic: A Childhood Memory](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363).

The program writes one sentence — a father running behind a bicycle, his
footsteps fading a little sooner each summer — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
when that variable is set, for local testing).
